Why it differs from a normal LLM

Autoregressive Gemma

  • Writes one token left to right
  • Past output is permanently fixed
  • Usually memory-bandwidth bound at batch 1
  • Excellent high-batch server throughput

DiffusionGemma

  • Predicts 256 positions per forward pass
  • Any token in the current canvas can be revised
  • Uses bidirectional context within the canvas
  • Compute-heavy; optimized for low concurrency
